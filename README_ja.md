# HTML-WYSIWYG

## 目的
コーディングエージェントと人間のやりとりを HTML を介して行うための VSCode 拡張。
AI には極力シンプルな HTML を出力させ、ユーザーにはモダンな WYSIWYG で閲覧・編集させる。

## コンセプト
- AI エージェントが出力するコンテキスト量を最小化する
- ユーザーはモダンなデザインで読みやすく、直感的に編集できる
- HTML を共通フォーマットとし、Confluence など外部ツールへの貼付けも容易にする

## 機能

### WYSIWYG 編集（インライン編集型）
- `.html` を対象とする
- WYSIWYG ビュー上で直接編集すると、裏の HTML ソースに即時反映される
- バンドル同梱の独自デフォルト CSS によりモダンな見た目を提供する
- HTML に直書きされた `style` 属性も尊重する（デフォルト CSS より優先）

### サポートする HTML
- インライン: `strong`, `em`, `code`, `a`, `span` ほか
- ブロック: `h1`〜`h6`, `p`, `blockquote`, `pre`, `hr`, `div`
- リスト: `ul`, `ol`, `li`
- テーブル: `table`, `thead`, `tbody`, `tr`, `th`, `td`
- メディア: `img`
- 独自タグ: `<comment>`（後述）

### 独自タグ
ユーザーへの可視性と AI への文脈注入を両立するためのカスタム要素:
- `<comment>...</comment>`: 注釈・背景情報を表すブロック。WYSIWYG では装飾枠で可視化され、AI からは通常の要素として読み取れる

### ショートカット
よく使う表記をキーボードとツールバーの両方から呼び出せる:
- キーボード: Ctrl+B (`<strong>`), Ctrl+I (`<em>`), Ctrl+K (`<a>`), `#` で見出し化 など
- フローティングメニュー: 選択範囲に応じて関連操作を提示
- ツールバー: 主要タグへのワンクリックアクセス

### クリップボードコピー
ドキュメント全体（または選択範囲）を 2 種類の形式でコピー可能:
- **HTML**: 標準的な HTML
- **Confluence 貼付け向け HTML**: Confluence エディタに貼り付けて崩れない素の HTML（`<table>`, `<pre>` などを正規化）

## 非対応 / 範囲外
- `<script>` の実行
- 外部 CSS / JS の読み込み
- フォーム送信（`<form>` 自体は表示するが送信は無効）

## 想定ユースケース
コーディングエージェントが生成する設計メモ・調査レポート・タスクリストを、人間が読みやすく整形しながら編集し、必要に応じて Confluence などの社内ドキュメントツールへ展開する。
