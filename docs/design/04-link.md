# 04. リンク機能

> 機能の存在については [README_ja.md](../../README_ja.md) を参照してください。このドキュメントは振る舞いの仕様を記述します。

## 概要

選択範囲または既存のリンクに対して、`<a href="...">` を挿入・更新・削除する。ダイアログで URL を入力し、確定後にリンクが適用される。

---

## 前提条件・入力

- カーソルが編集領域内にある
- 以下のいずれかの操作：
  - キーボードショートカット: `Ctrl+K`
  - ツールバーの「Link」ボタン
  - フローティングメニューの「Link」ボタン

---

## 振る舞い

### リンクダイアログの表示

1. `Ctrl+K` が押されると、現在の選択範囲を保存する（ダイアログがフォーカスを奪うため）
2. カーソルが既存の `<a>` 要素の中に collapsed で位置している場合、選択範囲をその `<a>` 全体に拡張する
3. モーダルダイアログが表示され、現在の URL が入力フィールドに表示される（新規の場合は空）
4. ダイアログには以下のボタンがある：
   - 「Insert」/「Update」（URL が空でない場合にアクティブ）
   - 「Remove」（既存の `<a>` がある場合のみ表示）
   - 「Cancel」
5. `Enter` キーで確定、`Escape` キーでキャンセル

### リンクの挿入（新規）

1. テキストが選択されている場合: 選択範囲を `<a href="URL">` でラップする
2. カーソルが collapsed で `<a>` の外にある場合: URL 文字列自体をテキストとする `<a>` 要素を挿入し、選択範囲をその内容に移動する

### リンクの更新

1. カーソルが既存の `<a>` 内にある（または `<a>` 全体を選択している）場合: その `<a>` の `href` 属性を新しい URL で更新する

### リンクの削除

1. ダイアログで「Remove」を選択した場合: 対象の `<a>` をアンラップする（子ノードを保持したまま `<a>` タグのみ除去）
2. 空の URL で「Insert」を実行した場合も同様に削除する

### 複数のリンクが選択範囲に含まれる場合

1. 選択範囲内のすべての既存 `<a>` 要素をアンラップする
2. 新しい URL が指定されていた場合、アンラップ後の範囲全体を新しい `<a>` で囲む
3. DOM 変更後にテキストノード参照を使って選択範囲を再構築する

---

## ツールバーのアクティブ状態

- カーソルが `<a>` 要素の内部（または直接的な祖先として `<a>` を持つ）場合にアクティブ状態（ハイライト）になる

---

## 出力・副作用

- `<a href="URL">` タグが DOM に挿入・更新・削除される
- 挿入後の選択範囲は `<a>` の内容全体に設定される
- `editor.notifyChanged()` が呼ばれ、250ms デバウンス後に Extension に同期される

---

## 制約・非対応

- ブロック境界をまたぐリンクの作成はできない（`<a>` はインライン要素のため、HTML の仕様外）
- JavaScript URL（`javascript:` スキーム）はサニタイズで除去される
- リンクに `target` 属性（別タブで開くなど）を設定するUIはない
