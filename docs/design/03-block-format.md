# 03. ブロック書式設定

> 機能の存在については [README_ja.md](../../README_ja.md) を参照してください。このドキュメントは振る舞いの仕様を記述します。

## 概要

カーソルが属するブロック要素のタグを変更する（`<p>` → `<h1>` など）、または水平線を挿入する。複数行の選択がある場合は、カーソルの開始位置が属するブロックを対象とする。

---

## 前提条件・入力

- カーソルが編集領域内にある
- 以下のいずれかの操作：
  - ツールバーのブロックタイプドロップダウン（Plain / H1–H6 / Blockquote）を選択
  - キーボードショートカット: `Ctrl+Shift+1`〜`Ctrl+Shift+6`（H1–H6）、`Ctrl+Shift+0`（Plain）
  - ツールバーの「Code block」ボタン（`<pre>` のトグル）
  - ツールバーの「HR」ボタン（水平線挿入）

---

## 振る舞い

### ブロックタグの変更

1. カーソルの開始位置から最近傍のブロック祖先要素（`P`, `H1`–`H6`, `BLOCKQUOTE`, `PRE`, `DIV`, `LI`）を探す
2. 新しいブロック要素を作成し、元の要素のすべての属性をコピーする
3. 元の要素のすべての子ノードを新しい要素に移動する
4. 元の要素を新しい要素で置き換える
5. カーソルを新しいブロックの末尾に移動する

### Code block トグル

- 現在のブロックタグが `<pre>` でない場合: `<pre>` に変換する
- 現在のブロックタグが `<pre>` の場合: `<p>` に戻す

### 水平線の挿入

1. 現在のブロックの直後に `<hr>` を挿入する
2. `<hr>` の直後に空の `<p>` を挿入する
3. 元のブロックが空だった場合、元のブロックを削除する
4. カーソルを新しい `<p>` の先頭に移動する
5. ブロック祖先が見つからない場合は、編集領域の末尾に `<hr>` と `<p>` を追加する

---

## ツールバードロップダウンの動作

- ドロップダウンを開く前に現在の選択範囲を保存する（フォーカスが外れる前に）
- オプション選択後に選択範囲を復元してからコマンドを実行する
- `selectionchange` イベントで現在のブロックタグをリアルタイムに表示に反映する
- ドロップダウンのパネルは `<body>` 直下に配置され、ツールバーのオーバーフロークリッピングを回避する（`position:fixed`）

---

## 出力・副作用

- カーソルが属するブロック要素のタグが変更される（属性・内容は保持）
- ツールバーのドロップダウン表示が新しいブロックタグに更新される
- `editor.notifyChanged()` が呼ばれ、250ms デバウンス後に Extension に同期される

---

## 制約・非対応

- テーブルセル（`<td>` / `<th>`）内のブロックタグは変更できない（`LI` と同様にネスト内のため）
- 複数ブロックを一括で変換することはできない（カーソルの開始位置の単一ブロックのみが対象）
- `<li>` を `<p>` などに変換することはできない（`<ul>` / `<ol>` との関係を考慮していない）
