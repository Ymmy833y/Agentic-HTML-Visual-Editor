# 08. ペースト機能

> 機能の存在については [README_ja.md](../../README_ja.md) を参照してください。このドキュメントは振る舞いの仕様を記述します。

## 概要

外部からクリップボードに貼り付けられた HTML をサニタイズしてエディタに挿入する。セキュリティ上問題のあるタグ・属性の除去と、ノイズとなるスタイル情報の削減の2段階でクリーンアップされる。

---

## 前提条件・入力

- カーソルが編集領域内にある
- クリップボードに内容がある
- 以下のいずれかの操作：
  - `Ctrl+V`（通常ペースト）
  - `Ctrl+Shift+V`（プレーンテキスト強制ペースト）

---

## 振る舞い

### HTML ペースト（通常ペースト）

1. クリップボードに `text/html` 形式のデータがある場合、HTML として処理する
2. **第1段階（セキュリティサニタイズ）**: `sanitizeFragment()` を実行する
   - `script`, `iframe`, `object`, `embed`, `frame`, `frameset`, `noscript`, `link`, `style`, `base`, `meta` タグを削除する
   - `on*` 属性（イベントハンドラ）を削除する
   - URL 属性（`href`, `src` など）に `javascript:`, `vbscript:`, `data:text/html` を含む値を削除する
3. **第2段階（ノイズ削減）**: `cleanupPastedFragment()` を実行する
   - CF_HTML コメントノード（`<!--StartFragment-->` / `<!--EndFragment-->` など）を削除し、隣接する余分な空白を除去する
   - Office / XML 名前空間タグ（`<o:p>`, `<w:sdt>` など）をアンラップする（内容を保持）
   - スタイル属性を許可リストに基づいてプルーニングする（後述）
   - `class` 属性をすべて削除する
   - スタイルをすべて失った `<span>` / `<font>` タグをアンラップする
4. サニタイズ済みのフラグメントをカーソル位置に挿入する（選択範囲がある場合は置換）

### スタイル属性の許可リスト

| 許可されるスタイルプロパティ | 対象タグ |
|---|---|
| `color`, `background-color` | すべての要素 |
| `text-align` | ブロック要素（`p`, `h1`–`h6`, `blockquote`, `pre`, `div`, `li`, `td`, `th`） |
| `width`, `min-width`, `max-width` | テーブル要素（`table`, `col`, `colgroup`, `th`, `td`） |
| `width`, `height` | `<img>` |

上記以外のすべてのスタイルプロパティ（`font-family`, `font-size`, `letter-spacing`, `line-height`, ベンダープレフィックスなど）は削除される。

### プレーンテキストペースト（`Ctrl+Shift+V`）

1. `keydown` イベントで `Ctrl+Shift+V` を検知してフラグを設定する
2. 次の `paste` イベントでフラグを確認し、HTML データを無視してプレーンテキスト（`text/plain`）のみを取得する
3. テキストノードとして直接挿入する（HTML 解釈なし）

### プレーンテキストのみのペースト

- クリップボードに `text/html` がなく `text/plain` のみの場合: ブラウザのデフォルトのペーストをそのまま許可する

---

## 出力・副作用

- カーソル位置にサニタイズ済みのコンテンツが挿入される（選択範囲がある場合は選択内容が置換される）
- 挿入後にカーソルはコンテンツの末尾に移動する
- `editor.notifyChanged()` が呼ばれ、250ms デバウンス後に Extension に同期される

---

## 制約・非対応

- 画像のインラインペースト（`data:image/...` URL は許可されるが実用的なサポートは限定的）
- スタイル情報の多くは削除されるため、Microsoft Word や Google Docs からの装飾的なスタイルは保持されない
- プレーンテキスト強制ペーストでは改行がテキストノードとして挿入され、ブロック構造には変換されない
