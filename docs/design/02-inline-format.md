# 02. テキスト書式設定（インライン）

> 機能の存在については [README_ja.md](../../README_ja.md) を参照してください。このドキュメントは振る舞いの仕様を記述します。

## 概要

選択範囲に対してインライン書式（太字・斜体・コード・打ち消し線）をトグルする。選択範囲全体が対象の書式で覆われている場合は除去し、一部でも覆われていない場合は全体に適用する。

---

## 前提条件・入力

- 選択範囲が空（collapsed）でない
- 以下のいずれかの操作：
  - ツールバーの Bold / Italic / Strikethrough / Inline Code ボタンをクリック
  - キーボードショートカット: `Ctrl+B`（太字）、`Ctrl+I`（斜体）
  - 対応する書式タグ: `<strong>`, `<em>`, `<code>`, `<s>`

---

## 振る舞い

### 正常系（書式適用）

1. 選択範囲内のすべてのテキストを検査する（`<comment-body>` / `<comment-reply>` 内のテキストは除外）
2. 1文字でも対象の書式タグで覆われていないテキストがある場合、選択範囲全体に書式を適用する
3. 適用はブロック境界・`<comment>` 境界を越えない。複数ブロックにまたがる選択は「セグメント」に分割して各セグメントに個別適用する
4. 選択後に隣接する同一タグを統合し、空の書式要素を除去する（正規化）

### 正常系（書式除去）

1. 選択範囲内のすべてのテキストが対象の書式タグで覆われている場合、書式を除去する
2. 書式タグが選択範囲を部分的にしか覆っていない場合（選択範囲が書式タグをまたいでいる場合）、書式タグを3分割して選択範囲内の部分のみ除去する：
   - タグが選択範囲の左にはみ出している場合: `[はみ出し部分は維持]` + `[選択範囲部分は除去]`
   - タグが選択範囲の右にはみ出している場合: `[選択範囲部分は除去]` + `[はみ出し部分は維持]`
   - タグが選択範囲の両側にはみ出している場合（選択範囲がタグ内に収まる）: `[左部分は維持]` + `[選択範囲部分は除去]` + `[右部分は維持]`

### 書式のクリア（すべて除去）

`Ctrl+\` または ツールバーの「Clear formatting」ボタン:

1. 選択範囲から以下のタグをすべてアンラップする: `strong`, `em`, `code`, `s`, `del`, `u`, `mark`, `sub`, `sup`, `span`, `font`
2. 選択範囲に完全に含まれる要素の `style` 属性と `class` 属性を削除する（部分的に覆われる要素の属性は変更しない）
3. `<a>` タグは除去対象外（リンクは書式ではなくナビゲーションとして扱う）

### ツールバーのアクティブ状態

- カーソルが collapsed（選択なし）の場合: カーソル位置に対象書式の祖先要素が存在するかで判定
- 選択がある場合: 選択範囲内のすべてのテキストが対象書式で覆われているかで判定（「全体カバー = アクティブ」）

---

## セグメント分割の仕様

以下の要素がセグメント境界として機能する（`SEGMENT_BOUNDARY_TAGS`）:

`P`, `H1`–`H6`, `BLOCKQUOTE`, `PRE`, `DIV`, `LI`, `TD`, `TH`, `CAPTION`, `COMMENT`

選択範囲がこれらの境界をまたぐ場合、各セグメントに独立して書式が適用される。`<comment>` 要素では `<comment-body>` より前のテキスト（対象テキスト）のみが対象となる。

---

## 出力・副作用

- DOM に `<strong>` / `<em>` / `<code>` / `<s>` タグが挿入または除去される
- ブラウザが自動挿入する `<b>` / `<i>` タグは入力直後に `<strong>` / `<em>` へ変換される（`normalizePresentationalTags()`）
- 操作後に選択範囲の復元が試みられる（DOM変更により正確に復元できない場合がある）
- `editor.notifyChanged()` が呼ばれ、250ms デバウンス後に `edit` メッセージが Extension に送られる

---

## 制約・非対応

- `<pre>` ブロック内のテキストにインライン書式を適用することはできない（セグメント境界のため）
- テーブルセル（`<td>` / `<th>`）をまたいだインライン書式の適用はできない
