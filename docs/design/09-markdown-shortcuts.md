# 09. マークダウンショートカット

> 機能の存在については [README_ja.md](../../README_ja.md) を参照してください。このドキュメントは振る舞いの仕様を記述します。

## 概要

特定のパターンをタイプすることで、自動的にブロック要素を変換する Markdown 風のショートカット。すべて `beforeinput` イベントをインターセプトして処理される。

---

## ショートカット一覧

### `# ` → 見出しに変換

- **条件**: カーソルが `<p>` ブロック内にあり、空白入力前の段落先頭のテキストが `#` のみ（1〜6文字）
- **動作**:
  1. `<p>` 先頭の `#` 文字を削除する
  2. `#` の数に応じて `<h1>` 〜 `<h6>` に変換する（`#` 1つ → `<h1>`、`##` → `<h2>`、最大 `######` → `<h6>`）
  3. カーソルを変換後の見出し要素の先頭に移動する
- **例**: `<p>## </p>` の `##` の後にスペースを入力すると `<h2></h2>` に変換される

### `--- + Enter` → 水平線に変換

- **条件**: カーソルが `<p>` ブロック内にあり、その段落のテキスト（前後の空白を除く）が `---` のみ
- **動作**:
  1. `<p>` を `<hr>` に置き換える
  2. `<hr>` の直後に空の `<p>` を挿入する
  3. カーソルを新しい `<p>` の先頭に移動する
- **例**: `<p>---</p>` で Enter を押すと `<hr>` + 空 `<p>` になる

### Enter → 書式継承

- **条件**: カーソルがブロックの末尾にあり、末尾のテキストがインライン書式（`<strong>`, `<em>`, `<code>`, `<s>`）で囲まれている
- **動作**:
  1. 現在のブロックと同じタグの新しいブロックを作成する
  2. 末尾のインライン書式チェーンを再現して新しいブロックに追加し、最内側にカーソルを置く
  3. 継続入力がその書式を引き継ぐ
- **注意**: この空の書式ラッパーは、カーソルがそのブロックに留まっている間のみシリアライズ時に保持される。カーソルが移動すると空のラッパーは次回のシリアライズで削除される
- **対象外**: `<li>` と `<pre>` は書式継承 Enter の対象外

### Enter → ネストリスト内の新規アイテム挿入

- **条件**: カーソルが `<li>` 内にあり、その `<li>` がネストされた `<ul>` / `<ol>` を子に持つ
- **条件（続き）**: カーソルの後にはネストリスト以外の実質的なコンテンツがない
- **動作**:
  1. ネストされたリストの先頭に新しい空の `<li>` を挿入する
  2. カーソルを新しい `<li>` の先頭に移動する
- これはブラウザのデフォルト動作（`<li>` を分割してネストリストを切り離す）を上書きする

---

## 優先順位

各ショートカットは以下の順序でチェックされる（`beforeinput` ハンドラ内）：

1. **スペース入力時**: 見出しショートカット (`handleHeadingShortcut()`)
2. **Enter 入力時**:
   1. ネストリストの Enter (`handleEnter()`)
   2. 書式継承 Enter (`handleFormattedEnter()`)
   3. 水平線変換 (`handleThematicBreakShortcut()`)

いずれかが `true` を返した時点で `e.preventDefault()` が実行され、残りのチェックとブラウザのデフォルト動作がキャンセルされる。

---

## 出力・副作用

- DOM のブロック要素が変換または新規作成される
- `editor.notifyChanged()` が呼ばれ、250ms デバウンス後に Extension に同期される
- 変換は取り消しできない（`Ctrl+Z` は VS Code の undo が担当）

---

## 制約・非対応

- `##` → H2 などの変換は `<p>` タグ内のカーソルのみで動作する（他のブロックタイプでは動作しない）
- 行頭でないと変換が起きない（`abc # ` と入力しても変換されない）
- `---` ショートカットは `<p>` タグのみ対象（他のブロックでは変換されない）
